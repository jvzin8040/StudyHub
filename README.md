# 🎓 StudyHub - A Plataforma Definitiva

> Projeto desenvolvido por alunos do 2º Semestre da FATEC. O **StudyHub** é um sistema centralizado criado para unificar e simplificar a rotina acadêmica dos estudantes.

## 📖 Sobre o Projeto

Atualmente, os estudantes precisam lidar com uma grande fragmentação de ferramentas digitais (Google Meet, Classroom, Teams, Moodle, E-mails, etc.) para acompanhar aulas, atividades e avisos. Essa divisão dificulta a organização da rotina acadêmica, impactando diretamente o rendimento e a gestão do tempo.

O **StudyHub** surge para solucionar essa problemática. É um site web centralizado, acessível diretamente pelo navegador, que substitui a navegação por múltiplos canais, reunindo tudo o que o aluno precisa em um único ambiente.

## ✨ Principais Funcionalidades

* 🏠 **Dashboard Inicial:** Um hub central que exibe as instituições matriculadas e permite a alternância rápida entre turmas, oferecendo um painel personalizado com acesso a todas as funcionalidades do semestre.
* 📝 **Gerenciamento de Atividades:** Centraliza as tarefas dos professores. Permite filtrar por temas/turmas, enviar trabalhos em diversos formatos, definir prioridades de entrega e receber feedbacks.
* 📅 **Agenda Estudantil:** Acompanhamento de prazos, avisos e eventos agendados com visualização em formato de calendário ou lista.
* 📊 **Estatísticas Rápidas:** Gráficos intuitivos sobre notas, faltas e situação nas disciplinas, além de recomendações automáticas de prioridade para as tarefas pendentes.
* 📁 **Controle de Curso e Documentação:** Reúne informações institucionais, histórico de notas/faltas, emissão de documentos acadêmicos e normas de matrícula.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído focando em uma interface fluida, moderna e responsiva, aliada a um banco de dados relacional robusto.

**Front-end:**
* HTML5
* CSS3
* JavaScript
* Bootstrap
* XAML

**Back-end & Banco de Dados:**
* Padrão de Arquitetura: **MVC (Model-View-Controller)**
* Banco de Dados: **MySQL** (Gerenciado via PHPMyAdmin)

## ⚙️ Arquitetura do Software

A aplicação adota o padrão **MVC**, garantindo uma separação limpa de responsabilidades:
* **View (Interface):** Construída com tecnologias web modernas (HTML, CSS, JS, Bootstrap) para navegação fluida em qualquer dispositivo.
* **Model/Controller (Lógica e Dados):** Modelagem de dados relacional (MySQL) utilizando chaves primárias e estrangeiras para garantir a total integridade e segurança dos registros acadêmicos e sincronização com sistemas externos.

## 🚀 Impactos Esperados

* Redução da perda de prazos de trabalhos e atividades.
* Diminuição do estresse causado pela descentralização de informações.
* Melhoria na gestão de tempo dos estudantes.
* Comunicação mais transparente e eficiente entre instituição, docentes e alunos.
